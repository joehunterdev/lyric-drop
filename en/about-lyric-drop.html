About Lyric Drop

Lyric Drop is a browser-based tool for adding synchronized lyrics to short-form video — built entirely in React and TypeScript by Joe Hunter, a full-stack developer based in Spain.

The problem it solves

Every tool for adding lyrics to video — CapCut, Canva, Premiere — treats the problem the same way: type each line manually, position it at a timestamp, repeat 40 times. For a full song lyric video, that means an hour of tedious work before you've even checked the timing.

Lyric Drop inverts the process. You paste the entire lyric sheet, set the start and end of the song on a visual timeline, and the app distributes the lyrics automatically. Real-time preview, then export. The whole thing in under 10 minutes.

Why Joe built it

Joe is a full-stack developer who builds tools that solve real problems for real people. Lyric Drop started as a personal frustration — watching musicians and content creators spend hours on lyric videos when the actual creative work should take minutes.

It's also a deliberate technical exercise: real-time video processing in the browser using FFmpeg.wasm, a visual timeline built from scratch in React, and a UX that works as intuitively on mobile as on desktop.

Tech stack

React + TypeScript

Component architecture with strict typing throughout.

FFmpeg.wasm

Client-side video processing — no server, no uploads, no privacy concerns.

Vite + Tailwind CSS

Fast builds and a utility-first styling system.

Canvas API

Real-time lyric rendering directly onto the video frame.
